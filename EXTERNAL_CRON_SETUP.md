# Внешний cron для уведомлений о вебинарах

Vercel Cron в проекте больше не настроен: файл `vercel.json` удалён. Endpoint остаётся обычным серверным API-маршрутом Vercel и вызывается внешним сервисом по HTTPS.

## 1. Переменная окружения

В Vercel откройте **Project → Settings → Environment Variables** и добавьте:

```text
CRON_SECRET=<длинная случайная строка>
```

Используйте не менее 32 случайных символов. Значение должно храниться также в защищённом хранилище секретов внешнего cron-сервиса. Не добавляйте `CRON_SECRET` в Git, в клиентский код и в переменные с префиксом `NEXT_PUBLIC_`.

## 2. Настройка внешнего cron-сервиса

Создайте задание, которое запускается каждые пять минут. Сервис должен поддерживать исходящий HTTP GET-запрос с произвольным заголовком.

| Поле задания | Значение |
|---|---|
| URL | `https://ВАШ_ДОМЕН/api/cron/webinar-reminders` |
| HTTP method | `GET` |
| Schedule | Каждые 5 минут, например `*/5 * * * *` |
| Header name | `Authorization` |
| Header value | `Bearer ВАШ_CRON_SECRET` |

Вместо `ВАШ_ДОМЕН` укажите production-домен, например `https://district.example` или `https://your-project.vercel.app`. Не используйте preview-домен.

Endpoint принимает только точное значение заголовка:

```text
Authorization: Bearer <значение CRON_SECRET>
```

При отсутствии или несовпадении секрета он возвращает `401` и не выполняет проверку вебинаров.

## 3. Ручная проверка

После production-деплоя выполните локально:

```bash
curl -i \
  -X GET \
  -H "Authorization: Bearer $CRON_SECRET" \
  "https://ВАШ_ДОМЕН/api/cron/webinar-reminders"
```

Успешный ответ имеет HTTP-статус `200` и JSON с полями `processedWebinars`, `attempted`, `sent`, `skippedAlreadySent` и `failed`.

Проверка без правильного секрета:

```bash
curl -i "https://ВАШ_ДОМЕН/api/cron/webinar-reminders"
```

Должен вернуться ответ:

```text
HTTP 401
{"error":"Unauthorized"}
```

## 4. Тест определённого типа

Для тестового активного будущего вебинара можно дополнительно передать серверные query-параметры:

```bash
curl -i \
  -X GET \
  -H "Authorization: Bearer $CRON_SECRET" \
  "https://ВАШ_ДОМЕН/api/cron/webinar-reminders?force=15_minutes&webinar_id=WEBINAR_ID"
```

Допустимые значения `force`: `3_days`, `1_day`, `6_hours`, `15_minutes`.

> Такой запрос выполняет реальную рассылку всем зарегистрированным на указанный вебинар пользователям и записывает успешные отправки в журнал. Для изолированной проверки шаблона одному человеку используйте Telegram-меню администратора **«🧪 Тест уведомлений»**.

## 5. Настройка в cron-job.org

1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org/en/) и подтвердите email. Для защиты аккаунта включите двухфакторную аутентификацию.
2. Нажмите **Create cronjob**.
3. Укажите название, например `District webinar reminders`.
4. В поле URL укажите:

```text
https://ВАШ_ДОМЕН/api/cron/webinar-reminders
```

5. В расписании выберите запуск **каждые 5 минут**. Если сервис показывает отдельные поля времени, используйте минуты `0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50, 55` и все часы/дни.
6. В разделе метода запроса выберите `GET`.
7. В разделе дополнительных заголовков добавьте одну строку:

| Header | Value |
|---|---|
| `Authorization` | `Bearer ВАШ_CRON_SECRET` |

8. Включите сохранение результата запроса и уведомление при ошибке, затем сохраните задание.
9. Нажмите **Test run**. Успешный запуск должен показать HTTP `200`; `401` означает, что `CRON_SECRET` в Vercel и значение заголовка отличаются.

cron-job.org поддерживает произвольные пользовательские заголовки, запросы `GET`, тестовые запуски и периодичность вплоть до одного раза в минуту. Сервис ожидает завершения HTTP-ответа не более 30 секунд, поэтому при существенном росте числа получателей следует разделить рассылку на небольшие партии. [1] [2]

## 6. Передача гайда и кнопки трансляции

### PDF-гайд за сутки

1. В Telegram под реальной ролью admin откройте **«🔔 Уведомления»**.
2. Выберите вебинар → **«За 1 день»** → **«📎 Прикрепить PDF / документ»**.
3. Отправьте PDF следующим сообщением в личном чате с ботом.
4. Бот автоматически получит Telegram `file_id` и сохранит его в `webinar_notification_templates.file_id` вместе с типом файла. В Vercel и `.env.local` ничего добавлять не нужно.
5. Сначала сохраните текст через **«📝 Изменить текст»**, затем откройте **«🧪 Тест уведомлений»** и отправьте себе шаблон **«За 1 день»**. Сначала придёт текст, затем PDF-гайд.

### Кнопка «🚀 ВОЙТИ НА АРЕНУ DISTRICT»

1. Когда получите ссылку на трансляцию, откройте нужный вебинар через административное меню бота.
2. В поле `registration_url` укажите полный URL трансляции, начинающийся с `https://`.
3. Через **«🧪 Тест уведомлений»** отправьте себе шаблон **«За 15 минут»**.
4. В сообщении появится URL-кнопка **«🚀 ВОЙТИ НА АРЕНУ DISTRICT»**. Её увидят реальные участники только в боевом напоминании за 15 минут.

Не передавайте `CRON_SECRET`, `TELEGRAM_BOT_TOKEN`, `SUPABASE_SERVICE_ROLE_KEY` или Telegram `file_id` через публичные сообщения, Git или клиентский код.
