
## 6. Тестирование непосредственно в Telegram

После деплоя откройте с ботом личный чат под пользователем с `role = 'admin'` и выполните `/start`. В административном меню появится кнопка **«🧪 Тест уведомлений»**. Её не видят guest, student, curator и пользователь с ролью test, даже если у него включена маска admin.

### Отправка шаблона только себе

1. Нажмите **«🧪 Тест уведомлений»**.
2. Выберите **«📨 Отправить тестовое уведомление себе»**.
3. Выберите любой существующий вебинар.
4. Выберите один из четырёх шаблонов: **за 3 дня**, **за 1 день**, **за 6 часов** или **за 15 минут**.
5. Бот отправит соответствующее Telegram-сообщение только на ваш серверно сохранённый `bot_members.chat_id`.

Такая тестовая отправка не читает список зарегистрированных участников для рассылки, не создаёт строку в `webinar_reminder_sends`, не меняет `webinar_registrations` и не изменяет дату вебинара. Для проверки каждого из четырёх шаблонов повторите шаги 2–4, выбирая другой тип уведомления.

### Проверка cron-логики без отправки

1. Нажмите **«🧪 Тест уведомлений»**.
2. Выберите **«🔎 Проверить cron-логику без отправки»**.
3. Бот выполнит тот же поиск активных будущих вебинаров и контрольных точек, что и cron-endpoint.
4. В ответе будут показаны число активных вебинаров, число напоминаний, которые были бы отправлены сейчас, уже отправленные типы, некорректные получатели и найденные контрольные точки.

Этот режим является dry run: Telegram-сообщения не отправляются и таблица `webinar_reminder_sends` не изменяется.

## 7. Обновлённые шаблоны и вложения

Система использует четыре контрольные точки: `3_days`, `1_day`, `6_hours` и `15_minutes`. Тип `3_hours` больше не используется.

Если миграция `supabase/webinar_reminder_sends.sql` уже была применена ранее, обязательно выполните в Supabase SQL Editor дополнительную миграцию:

```text
supabase/webinar_reminder_sends_6_hours.sql
```

Она заменяет допустимый тип `3_hours` на `6_hours` в таблице журнала.

### Гайд и вложения

Текст, Telegram `file_id` и тип прикреплённого документа хранятся в `public.webinar_notification_templates`, а не в коде и не в переменных окружения. Реальный admin добавляет документ через Telegram: **«🔔 Уведомления»** → вебинар → момент напоминания → **«📎 Прикрепить PDF / документ»** → отправляет файл следующим сообщением. Бот получает `file_id` автоматически и сохраняет его в Supabase.

При отправке уведомления текст приходит первым, затем бот отправляет сохранённый документ отдельным сообщением. Файл можно удалить через **«🗑 Удалить прикреплённый файл»** либо сохранить уведомление без файла.

### Вход на трансляцию за 15 минут

Уведомление `15_minutes` показывает единственную URL-кнопку **«🚀 ВОЙТИ НА АРЕНУ DISTRICT»**. Её ссылка берётся из `webinars.registration_url`. Перед началом вебинара внесите в это поле ссылку на трансляцию. Если поле пустое или содержит некорректный URL, сообщение отправится без кнопки.

> Техническая отметка: инструкция актуализирована для текущей конфигурации напоминаний District.
