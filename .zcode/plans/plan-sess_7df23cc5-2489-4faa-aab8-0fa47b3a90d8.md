## Причёсываем личный кабинет ученика

### 1. Спокойнее неон по всему кабинету — `src/styles/cabinet.css`
Тематика (тёмный фон, киберпанк, неоновые акценты) остаётся, но «вырвиглазность» снижаем:
- уменьшаем радиусы/непрозрачность всех `box-shadow`-свечений и `text-shadow` примерно вдвое (сейчас `0 0 18px…0.3`, станут `0 0 10px…0.15` и т.п.);
- активный пункт меню: без `scale(1.05)`, `text-shadow` и «выстрела» свечения — просто тонкая синяя подложка + левая полоска;
- панели/кнопки/чипы: мягкие тени вместо неоновых ореолов, акцентные цвета остаются (cyan/orange), но без многослойных glow;
- структура и вёрстка не меняются.

### 2. Дорога курса — главный элемент (`CabinetShell.tsx` — `CourseMap`, + стили)
Геометрию не трогаем: точки уже считаются из массива `DEMO_STOPS` (`RM_PTS`, разрывы модулей, ширина канваса) — добавление/удаление занятий не потребует правки дороги.

Новое полотно (по второму референсу, поверх текущего фона `road.jpg`, приглушённее):
- дорога — слоистые SVG-штрихи: тёмная обводка-край (шире), тело полотна (серо-синий «асфальт»), светлые края, белая прерывистая центральная разметка;
- пройденный отрезок — чуть светлее полотно + тонкая цветная линия-подсветка модуля вместо текущей 26px неон-заливки с drop-shadow;
- остановки — аккуратные светящиеся «площадки» на дороге (как огни на реф-2): пройденные мягко горят цветом модуля, текущая — тёплая с пингом, заблокированные — приглушённые; таблички-плиты остаются, но спокойнее;
- фонари/мелкий световой декор сохраняем.

### 3. Navigator прокрутки под дорогой
- нативный скроллбар скрываем; под дорогой — тонкий трек-навигатор с бегунком, отражающим позицию в 74-точечном маршруте; клик/драг по треку — переход к месту пути; авто-центрирование на текущей остановке сохраняем.

### 4. Объединённый блок прогресса над дорогой (как реф-1, кольцевой индикатор)
Внутри той же панели «Твой путь по курсу» шапка-грид над дорогой:
- слева — SVG-кольцо прогресса с `%` в центре и подписью «Пройдено X из 74 занятий»;
- в центре — «Текущая тема»: чип цвета модуля `М3 · Геометрия` + название занятия;
- справа — жизни (сердечки) + таймер восстановления (существующий `LivesWidget` переоформляем в этот блок).

### 5. Чипы модулей компактнее
Один аккуратный ряд под дорогой: точка цвета, `М1`, название, диапазон занятий — меньше отступы/паддинги, при переполнении горизонтальный скролл.

### Проверка
Запускаю dev-сервер, открываю кабинет в браузере (screen-проверка: дорога, скролл, навигатор, прогресс-блок, адаптив), при необходимости правлю. Трогаем только `CabinetShell.tsx` и `cabinet.css`.
