# Страница /individual: подстраница той же гильдии

## 0. ЕДИНЫЙ СТИЛЬ С ГЛАВНОЙ — каркас всего плана
Страница выглядит как часть того же мира, а не отдельный сайт:
- Тот же фон: тёмно-синяя ночь, звёздное небо (2 слоя дрейфа), созвездия, HUD-скобки по углам, парящие математические символы, зерно+сканлайны — все сли переиспользуются с главной.
- Те же паттерны секций: kicker-метки «КВЕСТ 0X // … :: STATUS» (синие), заголовки Oswald с неоновым свечением и градиентной полосой-подчёркиванием, водяные слова- watermarks за секциями, кресты «+» по углам.
- Те же карточки: тёмные панели с постоянным неон-свечением рамок (синее/янтарное по смыслу), hover-подсветка, reveal-анимации fade-up при скролле.
- Бегущие data-strip строки с `+XP / LVL UP / ★` между ключевыми секциями.
- Палитра/токены — общие (уже сделано), кнопки в стиле главной (янтарный градиент, скругления, свечение), focus-visible золотой, `prefers-reduced-motion` гасит анимации.

## 1. Шапка
- Как на главной: XP-бар, кнопка «Войти» (заглушка).
- Логотип → `/` (назад на главную) + компактная ссылка «← Главная».
- Якоря: Наставник `#teachers`, Варианты `#formats`, Запись `#signup`, Уроки `#process`.

## 2. Hero — компактный (~65vh)
- Крошка «← District», kicker «ФОРМАТЫ ЗАНЯТИЙ // 5–11 КЛАСС».
- Заголовок «Занятия с наставником гильдии» + описание (индивидуальные и мини-группы до 5).
- Две карточки-выбора: «🗡 Одиночный рейд» → `#formats-solo`, «🛡 Командный сектор» → `#formats-group`, по 2–3 выгоды.
- Без гигантского District; фон — общие слои (п.0).

## 3. Наставник (#teachers) — карточка персонажа
- Как у наставника на главной: портрет с неоново-голубым свечением за силуэтом, плашка «Наставник гильдии · LVL 99», анимированные skill-бары (синие/янтарные по рангу), значки-ачивки (98 ЦТ, 4 года, БГУ).
- Панели: «Характеристики» + «Личное дело» (текущие данные).
- Отзывы — «ХРОНИКА ПОДВИГОВ»: существующий слайдер в общем стиле.
- Цен/услуг в секции нет. Лента цифр остаётся в новом стиле.

## 4. Варианты занятий — два представления для сравнения (метки A/B)
- **A (#formats)**: один блок, две подсекции-колонки (соло / группа), стиль блока «Не подошёл курс?» с главной.
- **B (#formats-solo, #formats-group)**: два отдельных полноформатных блока подряд со своими заголовками и мини-CTA к записи.
- Контент одинаковый; после вашего выбора лишний удаляю.

## 5. Принципы (#principles)
- Отдельной секцией: янтарные руны-номера, неон-заголовок, общий стиль п.0.

## 6. Запись (#signup) — переключатель формата + цены по преподавателям
- Табы [Одиночный рейд | Командный сектор] в стиле игровых кнопок.
- Условия + карточки-строки цен по каждому преподавателю (из Sanity-услуг: имя, услуга, цена, слоты).
- «Записаться» — существующая модалка, формат подставляется в сообщение.

## 7. Как проходят обучение (#process)
- Текущий таймлайн в стиле гильдии: неоновая синяя ось, ромбы-узлы, золотые номера, kicker «КВЕСТ …».

## 8. Диагностика (#diagnostic)
- «Вступительный квест»: янтарный eyebrow, шаги-руны, общий стиль.

## Порядок секций
Hero → Наставник (+хроника отзывов, цифры) → Варианты A → Варианты B → Принципы → Запись → Как проходят обучение → Диагностика; data-strip между «Запись» и «Уроки».
